# Assumption register

Every default this build took because a spec was missing, per
`DEV_PLAN.spec_sources.rule_when_missing`. Each one is labelled ASSUMPTION in the
code at the point it is used, and each is replaceable without touching callers.

`docs/04_ARCHITECTURE.md` and `docs/specs/` do not exist yet. Until they do, the
pipeline, roles and events come from `DEV_PLAN.domain_frame`, and the whole of
`packages/contracts` is provisional in the sense that the architecture file wins
when it arrives.
